# Установка и безопасная проверка

Этот пакет предназначен для локального read-only просмотра уже подготовленной
папки `CodexChatAudit`. Он не является инструментом управления чатами и не
выполняет переименование, перенос, архивацию или удаление.

## Что передавать пользователю

Передавайте всю папку `codex-history-organizer` вместе с подготовленной папкой
`CodexChatAudit`, если она нужна для просмотра. В аудит должны входить только:

- `inventory.csv`;
- `actions.csv`;
- `projects.md`;
- `project_summaries/*.md`.

Не включайте в пакет `.codex`, `auth.json`, токены, ключи, сырые JSONL-сессии,
SQLite-файлы и реальные проекты пользователя.

## Локальный запуск панели

Откройте PowerShell в папке плагина и выполните:

```powershell
python .\server\dashboard_server.py
```

Затем откройте `http://127.0.0.1:8787/`. По умолчанию сервер ищет аудит в
`..\CodexChatAudit` относительно папки плагина. Для другого расположения:

```powershell
$env:CODEX_HISTORY_AUDIT_DIR = 'C:\Path\To\CodexChatAudit'
python .\server\dashboard_server.py
```

Сервер слушает только локальный адрес и останавливается закрытием окна
PowerShell (`Ctrl+C`).

## Подключение к Codex

В корне пакета находятся `plugin.json`, `.codex-plugin/plugin.json` и
`mcp.json`. Они описывают локальный MCP-сервер и read-only skill. В Codex
используйте штатный раздел Sources/Plugins и выберите локальную установку или
загрузку пакета, если такой пункт доступен в вашей версии приложения.

После подключения проверьте, что сервер видит только три read-only операции:

- обзор истории;
- поиск сессий;
- сводка по проекту.

Если локальная установка плагинов недоступна, панель всё равно можно запускать
как обычное локальное приложение; это не требует изменения состояния Codex.

## Периодический сборщик

Сборщик использует существующий локальный анализатор и запускает его в режиме
чтения источника. Он создаёт или обновляет только файлы в `CodexChatAudit`:

```powershell
python .\maintenance\refresh_audit.py
```

Для настройки запуска каждые 15 минут от имени текущего пользователя:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\maintenance\install_refresh_task.ps1 -EveryMinutes 15
```

Скрипт только регистрирует задачу Windows. Он не удаляет файлы и не меняет
историю Codex. Интервал можно задать от 5 до 1440 минут.

После обновления экспорта открытая панель увидит данные при следующем цикле
автообновления. В верхней части панели отображается время последнего изменения
локального источника.

## Представления

На панели доступны пять режимов чтения:

- **Карта** — проектные группы и детальная боковая сводка;
- **Таблица** — плотное сравнение сессий;
- **Канбан** — сигналы ценности и необходимости ручной проверки;
- **Хронология** — последовательность последних событий;
- **Связи** — SVG-граф проектных направлений вокруг общего индекса.

Канбан и граф визуализируют сигналы аудита и не выполняют никаких действий над
чатами.

## Проверка перед передачей

Из корня репозитория:

```powershell
python -m unittest codex-history-organizer/tests/test_package.py codex-history-organizer/tests/test_history_store.py codex-history-organizer/tests/test_mcp_server.py codex-history-organizer/tests/test_dashboard_server.py -v
```

Браузерный smoke-тест требует установленного Playwright и запущенной панели:

```powershell
python codex-history-organizer/tests/playwright_history_dashboard.py --url http://127.0.0.1:8787/
```

## Граница безопасности

Плагин читает только подготовленные отчёты за пределами `.codex`. Он не открывает
исходные сессии и индексы, не читает credential-файлы и не имеет MCP-операций
записи. Любые будущие изменения истории должны выполняться отдельным процессом
после явного подтверждения пользователя, резервной копии и проверки официальной
поддержки текущей версии Codex.
