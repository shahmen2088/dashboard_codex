# Codex History Organizer

Локальный read-only плагин для навигации по подготовленному индексу истории
Codex. Он показывает карту проектов, ценность сессий, незакрытые задачи и
неопределённость классификации.

## Безопасность

- Плагин читает только `inventory.csv`, `actions.csv`, `projects.md` и
  `project_summaries/*.md` из папки аудита.
- Исходные сессии Codex, JSONL, индексы, SQLite и проекты не читаются и не
  изменяются.
- В первом релизе нет инструментов записи, архивации, переименования или
  перемещения чатов.

## Локальный запуск

По умолчанию данные ищутся в `../CodexChatAudit` относительно этого пакета.
Для другого расположения задайте `CODEX_HISTORY_AUDIT_DIR`.

Интерфейс и MCP-сервер будут добавлены в следующих этапах плана.
