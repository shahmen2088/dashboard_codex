# История Codex: локальное обновление и автообновление панели

## Цель

Сделать локальный сбор данных и визуальную панель независимыми от открытого
окна Codex: сборщик по расписанию обновляет только подготовленный экспорт, а
панель периодически перечитывает этот экспорт.

## Ограничения

- исходные сессии, индексы и SQLite читаются только в режиме чтения;
- `.codex`, реальные проекты и учётные данные не изменяются;
- панель не отправляет данные в сеть;
- установка задачи Windows не удаляет и не заменяет пользовательские файлы;
- ручное управление чатами не добавляется.

## Этапы

1. Добавить безопасный локальный запускатель существующего генератора аудита и
   скрипт регистрации периодической задачи Windows.
2. Сделать вывод генератора настраиваемым через переменную окружения, сохранив
   текущий формат `CodexChatAudit`.
3. Добавить в панель ручное обновление, отображение времени источника и выбор
   интервала автообновления.
4. Проверить сохранение выбранного проекта, поиска, обработку пустого аудита и
   браузерный сценарий.
5. Обновить инструкции и зафиксировать каждый этап отдельным Git-коммитом.

## Референсы интерфейса

- GitHub Projects: отдельные представления Table, Board и Roadmap;
- Linear: project views, timeline и статусные обновления;
- Notion: Timeline с группировкой, датами и подэлементами;
- Obsidian: локальный граф связей для контекстной навигации.

Для этой панели применяем их идеи без копирования интерфейса: компактная карта
направлений, фильтры, детальная боковая сводка и явный статус свежести данных.
